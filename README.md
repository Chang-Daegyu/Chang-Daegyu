## 📂 Projects

### 1. 스마트팩토리 공장 회전 설비 이상탐지 및 예지보전 (FactoryPdM)
- **설명**: 공장 회전 설비(모터 등)의 전류·진동 등 시계열 센서 데이터를 수집하여, 이상 징후를 탐지하고 고장을 사전에 예측하는 **스마트팩토리 예지보전 플랫폼**입니다.  
- **역할**: AI 모델링 · 백엔드 API 설계 · 데이터 파이프라인 및 모니터링 환경 구축  
- **기술**: Python, PyTorch, FastAPI, Kafka, TimescaleDB(PostgreSQL), Docker, Grafana, Prometheus

### 2. AI 기반 정치 콘텐츠 편향도 및 정확도 분석 플랫폼 (NEWSBALANCE)
- **설명**: 뉴스·정치 콘텐츠를 수집/전처리하고, AI 모델을 통해 **편향도 및 사실성(정확도)을 분석·시각화**하는 웹 플랫폼입니다.  
- **역할**: AI 분석 로직 설계, 백엔드 API 및 데이터베이스 모델링, 결과 리포트 구조 설계  
- **기술**: Python, FastAPI, OpenAI API, MySQL, Docker

### 3. 센서 기반 AI 러닝 헬스케어 앱 (TapeRunner)
- **설명**: 스마트폰 및 풋프린트/압력 센서 데이터를 활용해 러닝 패턴과 하중 분포를 분석하고, **부상 예방을 위한 피드백**을 제공하는 헬스케어 서비스입니다.  
- **역할**: 센서 데이터 파이프라인 설계, 특성 추출 및 모델링, 분석 API 구현  
- **기술**: Python, PyTorch, 1D-CNN, IMU/압력 센서 데이터 처리

### 4. 공공데이터 기반 미세먼지 농도 예측 프로젝트
- **설명**: 공공데이터 포털의 기상·대기질 데이터를 수집하여, 지역·시간대별 **미세먼지(PM) 농도 예측 모델**을 개발한 프로젝트입니다.  
- **역할**: 데이터 수집·정제, 피처 엔지니어링, 예측 모델 학습 및 평가  
- **기술**: Python, Pandas, scikit-learn, XGBoost  

---

### 5. 스마트폰 센서 데이터 기반 모션 분류 프로젝트
- **설명**: 스마트폰 내장 센서(가속도계, 자이로스코프 등)의 시계열 데이터를 활용해, **사용자의 동작/자세를 분류**하는 AI 모델을 구현한 프로젝트입니다.  
- **역할**: 시계열 데이터 전처리, 특징 추출, 분류 모델 설계 및 성능 개선
